**SMK Muhammadiyah 3 Purbalingga**

---

## 1. Memandu Siswa Login


1. Buka website ujian → klik **Mulai Asesmen**
2. Kolom **Nama**: ketik **2 huruf** → **klik nama di dropdown** (wajib)
3. **Kelas** akan terisi otomatis → pilih **Mapel: SIMULASI**
4. Klik **Mulai Ujian** → **Ya, Mulai!**

> Jika Kelas tidak terisi = belum klik dropdown. Ulangi ketik 2 huruf lalu klik.

---

## 2. Live Monitoring

Buka **admin_pro.html** → Login → Menu **Live Monitoring**

- **Filter:** pilih **Kelas** Anda dan **Mapel SIMULASI** sebelum pantau
- **Aktif** = sedang mengerjakan | **Selesai** = sudah kirim (✅) | **Pelanggaran** = buka tab lain (🚨)
- **✓ Bersih** = aman | **⚠️ 2x** = klik angka untuk lihat detail jam pelanggaran
- Angka update otomatis, jika tidak gerak → refresh

---

## 3. Masalah yang Sering Terjadi

| Masalah | Solusi |
| :--- | :--- |
| Nama tidak muncul | Cek ejaan. Jika tetap tidak ada, catat → lapor Admin |
| Mapel tidak muncul | Jadwal belum AKTIF → hubungi Admin |
| `Biodata Belum Lengkap` | Pastikan Nama, Kelas, Mapel terisi |
| `Sudah Menyelesaikan` | Siswa sudah kirim 1x. Hubungi Admin untuk reset |
| Jawaban tidak tersimpan / sinyal putus | Tunggu 30 detik (auto-simpan), jangan refresh. Klik `Coba Lagi` |
| Pelanggaran 1x padahal tidak buka tab | Notifikasi WA masuk → klik `Saya Mengerti`, lanjut kerjakan |

**Jika bingung >1 menit → hubungi Admin.**
